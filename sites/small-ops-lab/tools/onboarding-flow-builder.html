How to use this page

  1. Open the source guide and read the context first.
  2. Copy the template or run the calculator with one real, non-sensitive example.
  3. Check the output against the checklist below.
  4. Save the final version in your own document or project tool.

Checklist

  • Does onboarding start from a signed agreement and deposit?
  • Does the intake form collect the information the team actually needs?
  • Is the workspace structure consistent for every client?
  • Is access requested securely and tracked?
  • Are the first checkpoints scheduled automatically?

Example wording

Five-step onboarding flow

Signed agreement and deposit received → create project record and owner.

Intake form sent automatically → client submits goals, assets, access needs.

Workspace created → folders, task list, naming convention, permissions.

Access requested → secure invitations tracked with owners and due dates.

Checkpoints scheduled → kickoff, first update, first milestone review.

Do not skip

  • Automating a welcome email while inputs are still collected by hand.
  • Letting each project invent its own folder structure.
  • Emailing passwords or access codes.
  • Never reviewing where clients get stuck during onboarding.
Scope note

This page is an operational template, not legal, tax, or financial advice. Review the final wording with a qualified professional where the risk is material.
