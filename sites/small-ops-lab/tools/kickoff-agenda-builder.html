How to use this page

  1. Open the source guide and read the context first.
  2. Copy the template or run the calculator with one real, non-sensitive example.
  3. Check the output against the checklist below.
  4. Save the final version in your own document or project tool.

Checklist

  • Is the outcome written in the client’s words?
  • Does every input have an owner and a date?
  • Is each milestone a visible deliverable?
  • Is the communication rhythm agreed?
  • Are scope and change control restated in writing?

Example wording

Kickoff summary skeleton

Outcome: a five-page site that can take bookings without phone tag.

Owners: Maya approves design, Sam provides final copy, Alex owns build.

Milestones: sitemap approved Oct 8; design direction Oct 12; build complete Oct 20.

Rhythm: written update every Friday; urgent issues by email with URGENT in the subject.

Change control: new pages or integrations are quoted before work begins.

Do not skip

  • Starting production before the decision-maker is identified.
  • Leaving content, access, or approvals without owners.
  • Using vague milestones such as “work continues.”
  • Skipping the written kickoff summary.
Scope note

This page is an operational template, not legal, tax, or financial advice. Review the final wording with a qualified professional where the risk is material.
