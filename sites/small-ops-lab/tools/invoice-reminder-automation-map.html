Invoice reminder automation map

Build a reminder sequence that escalates the process while keeping the relationship human.

This template supports the guide How to automate invoice reminders without sounding robotic. Use it as a working draft, then adapt the wording and fields to your own contracts, client process, and jurisdiction.

How to use this page

  1. Open the source guide and read the context first.
  2. Copy the template or run the calculator with one real, non-sensitive example.
  3. Check the output against the checklist below.
  4. Save the final version in your own document or project tool.

Checklist

  • Did I map the manual process first?
  • Are the triggers based on real events?
  • Is each message short and actionable?
  • Is there a human review gate for disputes or final notices?
  • Am I measuring days-to-payment and reply rate?

Example wording

Automation map

Trigger: invoice issued → send delivery confirmation immediately.

Trigger: due date + 1 business day → send neutral reminder.

Trigger: due date + 7 days → send firmer reminder and new payment date.

Trigger: due date + 30 days → pause automation and request human review.

Trigger: payment received → stop sequence, update records, send receipt.

Do not skip

  • Automating an unclear or inconsistent process.
  • Sending the same message regardless of payment history.
  • Removing the human step from a sensitive or disputed invoice.
  • Never checking whether the automation actually improves collection time.
Scope note

This page is an operational template, not legal, tax, or financial advice. Review the final wording with a qualified professional where the risk is material.
