A script format that makes voice production easier

Separate spoken lines, direction, pronunciation, timing, and version notes without confusing the performer.

Reviewed October 28, 2026 · Practical operations guide · Advertising is labeled separately

Quick answer: Use one column or block for spoken text, a separate style for performance direction, inline pronunciation notes, version labels, and a change log. Keep the latest approved script in one place.

The problem

A screenplay format is not always the best format for a voice session. When direction, legal text, and spoken words are mixed together, performers read the wrong thing or miss a revision.

Make the spoken words unmistakable

The performer should be able to read the spoken copy without sorting through production notes. Use a clear visual style for spoken text and a different style for direction. Do not put critical pronunciation guidance inside a sentence that might be read aloud.

Separate direction from performance

Direction should describe the intention: “calm, slower, reassure the listener.” Avoid stacking adjectives that contradict each other. If a line needs a specific pause or emphasis, mark it with a symbol or a short note.

Version every script

Use a date, version number, and change log. Highlight changed lines and remove old versions from the recording folder. The most common studio error is recording from a stale copy while the client reviews a newer one.

Mark legal and disclosure lines

Synthetic-media disclosure, sponsor language, and regulated claims may need exact wording. Label them as locked copy. Do not let a performer improvise around them.

Add a short pre-session checklist

At the top of the script, include pronunciation guide link, runtime target, tone reference, required takes, file naming, and approval owner. This reduces setup questions and keeps the session focused on performance.

Example

Script block

VERSION: ep-014-v3 · approved 2026-10-28

TONE: calm, conversational, no hard sell.

SPOKEN: “The update is available today.”

DIRECTION: pause briefly before “today”; do not stress “available.”

PRONUNCIATION: Kalla = KAH-lah.

LOCKED LEGAL: “This narration contains a synthetic voice.”

Checklist

  • Are spoken words visually separate from direction?
  • Is there a version number and change log?
  • Are locked lines clearly labeled?
  • Is the pronunciation guide linked?
  • Does the script state the runtime target?

Mistakes to avoid

  • Mixing legal text into normal direction.
  • Sending several “final” versions without labels.
  • Using vague tone words with no reference.
  • Forgetting the pronunciation and runtime notes.

FAQ

Should I use a table or a document?

Use whichever the performer can read comfortably. The important part is consistent separation between spoken text and direction.

How should revisions be marked?

Use a change log, a new version number, and a clear highlight for changed lines. Do not rely on a chat message as the source of truth.

Can AI read my formatted script?

Often yes, but remove stage directions and keep pronunciation notes in a separate field or a clearly marked format the tool can handle.
