We audited all 32 tool profiles for evidence quality

This is the remediation record behind the SignalShelf rebuild: what the old pages could not prove, what changed, and what remains deliberately unclaimed.

Audit completed October 10, 2026 · Internal corpus review · No vendor sponsorship

Result: the previous build had 32 similarly structured tool pages, 10 research-based guides, and 3 recorded browser experiments. It did not have a hands-on test record for all 32 products. The rebuild removes the implication that every page is a full review and replaces it with an explicit evidence status and a reproducible trial.

Method

We inspected the generated tool pages, the source JSON, the experiment log, and the editor policy. We counted only evidence that could be pointed to in the repository: a captured prompt, an output file, a screenshot, a source URL, or a written method. Marketing copy and model generated summaries were not counted as independent evidence.

What this audit does not prove

It does not prove that every product is useful, that a vendor claim is true, or that a page will rank in search. It also does not turn a documentation review into a hands-on test. A profile can help a reader plan a trial, compare alternatives, and avoid unsupported claims; it cannot replace using the product on the reader's own work.

Why this is useful to a reader

  1. You can see whether a conclusion came from a source, a browser experiment, or editorial judgment.
  2. You can reject a tool before paying if the no-fit conditions match your situation.
  3. You can run the same trial on another tool and compare correction effort instead of marketing language.
  4. You can report a source error without the page hiding behind a generic disclaimer.

Next evidence work

The next useful step is not more pages. It is recording repeatable tests for the highest-value workflows: source verification, long-document editing, code review, meeting-note accuracy, image-text accuracy, and automation failure handling. A test will be added only when the input, output, date, method, and limitations can be preserved.
