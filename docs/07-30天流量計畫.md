# 30 天流量計畫

執行期間：2026-10-01 至 2026-10-30。

## 目標

- 讓 Search Console 完整處理 sitemap 與主要頁面索引
- 完成 20 個內容或刷新任務
- 每篇文章至少新增一個原創證據：實測、截圖、比較表、錯誤紀錄或來源核對
- 建立工具頁、分類頁、指南與實驗文章之間的主題連結
- 以 GSC 曝光、CTR 與排名決定下一批內容，而不是只看發文數量

## 每日節奏

- 週一：選題、查搜尋意圖、收集來源
- 週二：實測與截圖
- 週三：完成文章與內部連結
- 週四：事實檢查、更新日期、提交索引
- 週五：檢查 GSC、修正 CTR 與舊內容
- 週末：整理下週素材，不發佈沒有證據的內容

## 核心指標

| 指標 | 觀察週期 | 目標方向 |
|---|---|---|
| Sitemap 狀態 | 每日 1 次，之後每週 | 從無法擷取變成成功 |
| 已收錄網頁 | 每週 | 穩定增加 |
| GSC 曝光 | 每週 | 穩定增加 |
| CTR | 每週 | 有曝光但 CTR 低的頁面優先改標題 |
| 平均排名 | 每兩週 | 優先處理第 8 到 30 名字詞 |
| 自然點擊 | 每月 | 以趨勢判斷，不用短期數字下結論 |
