## Google 後續處理

Search Console 剛提交時可能顯示「無法擷取」或「資料處理中」，這通常是新資源首次處理中的狀態。應在 24 到 48 小時後重新檢查：

1. Sitemap 狀態是否變成「成功」。
2. 系統探索到的網頁數量是否接近 58。
3. URL Inspection 是否已將首頁標記為已收錄。
4. Page indexing 是否出現排除原因。
