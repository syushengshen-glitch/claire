# AdSense 合規與上線檢查

## 內容

- [ ] 每一頁都有明確主題，不是空殼頁或只有廣告
- [ ] AI 草稿已由真人補上實測、來源、截圖與判斷
- [ ] 沒有大量重複、模板化或同義改寫內容
- [ ] 沒有抄襲、盜圖、抓取他人評論或虛構體驗
- [ ] 工具功能、價格與限制都有更新日期
- [ ] 重要聲明有可查證的來源
- [ ] 導覽可以從首頁走到主要內容，沒有死頁

## 信任頁

- [ ] 隱私權政策
- [ ] Cookie 與同意管理
- [ ] 關於頁
- [ ] 聯絡方式
- [ ] 服務條款
- [ ] 聯盟揭露
- [ ] 編輯政策與更正方式

## 廣告設定

- [ ] AdSense 帳號已通過後才放入 publisher ID
- [ ] `site/ads.txt` 已改成正式 publisher 行
- [ ] 廣告有 `Advertisement` 或 `Sponsored` 標籤
- [ ] 廣告沒有偽裝成下載、導覽或主要操作按鈕
- [ ] 手機版廣告沒有遮住內容或造成版面跳動
- [ ] 沒有誘導點擊、自動重導或彈出式強制廣告
- [ ] 沒有在空白頁、錯誤頁或政策頁塞廣告

## 流量

- [ ] 沒有購買流量
- [ ] 沒有加入互點或 Paid-to-click 群組
- [ ] 沒有要求朋友或社群成員點擊廣告
- [ ] 沒有使用彈窗流量、強制下載或假預覽來源
- [ ] Search Console 沒有安全和手動處罰警告

## 技術

- [ ] HTTPS 正常
- [ ] `robots.txt` 沒有誤擋全站
- [ ] `sitemap.xml` 可讀取
- [ ] canonical 使用正式網域
- [ ] 手機版沒有水平滾動
- [ ] 搜尋與分類篩選可用
- [ ] 重要內容不需登入即可閱讀
- [ ] 404 頁不會被收錄
- [ ] 廣告載入失敗時內容仍可使用

## 上線後監控

- [ ] Google Search Console 檢查索引與查詢
- [ ] AdSense Policy Center 每週檢查
- [ ] 每月檢查高流量頁是否過時
- [ ] 每季刪除沒有需求、沒有流量且沒有內部價值的頁面
- [ ] 有價格、政策或產品停用變更時立即更新
