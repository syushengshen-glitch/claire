# AI 提示詞與審稿流程

## 1. 建站提示詞

```text
請幫我建立一個英文 AI tools directory 靜態網站，受眾是 small business owners、freelancers 和 remote teams。

網站必須：
- 風格像編輯索引，不要像一般 SaaS 卡片模板
- 7 個分類：Chat、Image、Coding、Writing and SEO、Video and Audio、Productivity、Business
- 32 個工具，每個工具都要有獨立頁面
- 支援搜尋、分類篩選、排序
- 每個工具頁包含：best for、strengths、limits、pricing note、alternatives、editorial note
- AdSense 廣告位：首頁段落之間、目錄中段、桌面側欄
- 所有廣告都要清楚標示 Advertisement
- 產出可直接部署到 Vercel 的靜態檔案
```

## 2. 關鍵字驗證提示詞

```text
我要做英文 AI 工具目錄網站。請針對以下主題幫我整理 30 個長尾關鍵字候選：

主題：{你的 niche}

每個候選請輸出：
- keyword
- search intent
- 可能的文章標題
- 適合連到的工具頁
- 是否偏商業意圖
- 不確定或需要查詢的資料

不要虛構搜尋量。搜尋量與難度欄位請標為「需要 Google Keyword Planner 或 Ahrefs 驗證」。
```

## 3. 文章大綱提示詞

```text
請依照以下真實資料製作文章大綱，不要直接寫成完整文章：

Primary keyword：{keyword}
讀者：{audience}
工具：{tools}
我提供的實測或觀察：{notes}

輸出：
1. 搜尋意圖
2. 文章要回答的 5 個問題
3. H2/H3 結構
4. 需要查證的事實
5. 應加入的內部連結
6. 適合放廣告的位置
7. 哪些段落必須由真人補充經驗

不要編造數據、價格、測試結果或引用來源。
```

## 4. 初稿提示詞

```text
請根據已核准的大綱產生英文初稿。

限制：
- 不使用空泛的 “in today’s fast-paced world” 開頭
- 不編造測試、數據、價格或評論
- 每個工具都要寫適合誰、限制、什麼情況下不要選
- 段落小於 80 個英文字元的視覺行長由網站 CSS 控制，不使用硬換行
- 加入清楚、自然的內部連結，不要堆關鍵字
- 將不確定的事實標成 [VERIFY]
- 輸出 Markdown，不要直接發佈
```

## 5. 真人審稿提示詞

```text
你是嚴格的事實與編輯審稿者。請檢查下面文章：

- 哪些句子沒有來源
- 哪些產品功能可能過時
- 哪些建議只是 AI 的推測
- 哪些段落與其他 AI 工具文章高度相似
- 哪裡缺少第一手經驗
- 哪些內部連結不合理
- 哪些廣告位置會干擾閱讀
- 哪些說法帶有未經證明的收入承諾

請輸出修改清單，不要只給我稱讚。
```

## 6. 100 篇規劃提示詞

```text
請根據 docs/02-content-plan.csv 的主題，選出最可能有搜尋需求的 10 篇 P1 文章。

每一篇請給我：
- 搜尋意圖
- 搜尋結果前三名的內容缺口
- 我能提供的原創角度
- 3 個需要實際測試的工具
- 必須查證的事實
- 可連到的工具頁與其他文章
- 預估需要的人工工作

不要一次生成 100 篇文章，也不要假裝你查過搜尋量。
```

## 發佈前人工檢查

1. 每個價格、功能和地區限制都在廠商官網確認。
2. 至少有一個其他來源支持關鍵結論。
3. 文章有自己的測試或清楚標示為 editorial judgment。
4. 檢查沒有誇大收入、保證排名或保證通過 AdSense。
5. 確認 AdSense 廣告沒有遮住內容、下載或主要操作。
6. 更新頁面上的 reviewed date 與 sitemap lastmod。
